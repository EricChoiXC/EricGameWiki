# 数据库公共规范

## 数据库规范

统一使用 mysql8.0+ 数据库，`utf8mb4_0900_ai_ci` 编码

## 表规范

统一使用 `${模块名}_${次级模块名}_${业务名}_$(次级业务名}...` 的顺序命名

如： `sys_org_user` 表示 系统-组织架构-用户；
`sys_org_user_post` 表示 系统-组织架构-用户-所属岗位；
`sys_attachment_main` 表示 系统-附件-主表
`sys_attachment_main_record` 表示 系统-附件-主表-记录

## 字段规范

- 数据库字段统一使用 `field_` 前缀
- 公共字段优先复用以下命名和数据结构：
    - 主键 `field_id` varchar(32)
    - 编号 `field_no` varchar(50)
    - 名称/标题 `field_name` varchar(200)
    - 创建人 `field_creator_id` varchar(32)
    - 创建时间 `field_create_time` datetime
    - 更新人 `field_updator_id` varchar(32)
    - 更新时间 `field_update_time` datetime
    - 是否启用 `field_enable` tinyint
    - 版本号 `field_version` int
- 除 `field_id`, `field_version`, `field_enable`，和特殊要求的字段外，所有字段在数据库中均不直接设置 `NOT NULL`
- 表结构、字段类型、索引、外键约束以数据库设计文档为准
