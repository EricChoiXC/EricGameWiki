# 图鉴类

## 列表页面

> 访问路径 `/wiki/${wikiMain.fieldSimpleName}/${wikiMainData.fieldDataName}`

### 页面布局

上下拆分筛选区和不分页列表；

筛选区提供："关键字" 筛选，模糊匹配数据项表的数据项名称、数据项编号；

列表区不分页显示查询结果，列表仅列出：数据项名称、数据项简称；行点击打开浏览器新标签进入数据项详情页；

## 详情页面

> 访问路径 `/wiki/${wikiMain.fieldSimpleName}/${wikiMainData.fieldDataName}/${fieldId}`

按 `wiki_main_data_wiki_page` 的配置，按表格显示数据信息；
