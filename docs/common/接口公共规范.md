# API 接口设计通用规范

> 本文档为 EricGameWiki 项目各模块 API 接口设计文档的公共规范公约。
> 各模块 API 设计文档应引用本文档，并在正文中声明"通用规范遵循本文档，不再重复编写"。
> 涉及非通用（模块特有）的章节，各模块文档仍需要自行编写。

## 2. 文档定位与输入依据（模板约定）

### 2.1 契约源策略

- **人类可读设计文档**: 模块级 API 设计文档
- **机器可读契约文件**: 暂无，后续由 API 设计文档生成 `openapi.yaml`
- **同步规则**: API 设计文档为上游设计，实现后生成机器契约并保持同步

### 2.2 事实源优先级

| 优先级 | 文档类型 | 冲突处理规则 |
|--------|----------|--------------|
| P0 | 本 API 设计文档 | 接口路径、方法、参数、响应以本文档为准 |
| P1 | 上游业务逻辑/需求文档 | 业务流程、角色权限、异常处理以业务逻辑文档为准 |
| P2 | 数据库设计文档 | 表结构、字段以数据库设计文档为准 |
| P3 | 代码现状 | 实现过程中发现的问题需同步更新本文档 |

## 3. 通用契约规范

### 3.1 版本、命名与路径

- **Base path**: `/api/v1/{系统名}/{模块}/{次级模块}`（各模块按自身业务填充）
- **版本策略**: 无版本前缀，通过向后兼容保证平滑升级
- **命名规范**: 资源路径统一使用英文小写，多词以 `/` 层级分隔

### 3.2 鉴权、授权与审计

- **认证方式**: 登录返回 JWT Token，前端在请求头携带 `Authorization: Bearer <token>`
- **授权方式**: 每个写接口通过对应 `Resolver` 校验当前用户是否拥有操作权限；权限模型为 RBAC（权限→角色→用户）
- **审计要求**: 写操作（增/删/改）统一记录审计日志

### 3.3 查询接口约定

- **分页**: 请求参数统一使用 `pageNum`（从 1 开始）、`pageSize`；响应统一使用 `total`、`pages`、`records`
- **排序**: 请求参数使用 `sortField` + `sortOrder`（`asc`/`desc`）
- **筛选**: 各查询条件直接作为请求 body 的字段传入
- **搜索**: 关键词模糊搜索统一使用 `keyword` 字段

### 3.4 写接口约定

- **创建**: `/save` 返回新创建记录的 `field_id`
- **更新**: `/update` 使用 `PATCH`，支持部分字段更新
- **删除**: `/delete` 使用 `DELETE`，物理删除或逻辑删除由具体接口决定
- **幂等策略**: N/A（不要求幂等）

### 3.5 通用请求报文格式

```json
{
  "data" : {
    /*接口请求的VO类对象*/
  },
  "query" : {
    /*分页请求信息*/
    "pageNum" : 1, /*页码，从1开始*/
    "pageSize" : 15, /*每页记录数，默认15*/
    "needPage" : true /*当此处为 false 时，查询不分页*/
    "data" : {
      /*查询条件，具体结合 [查询标准.md](/docs/common/查询标准.md) 文档*/
    }
  },
  "map" : {
    /*除上述内容以外的其他参数*/
  }
}
```

> `data`对象要求能转化为后端的VO类对象，优先仅传入数据库表有的字段

### 3.6 通用响应报文格式

```json
{
  "success" : true, /*是否成功*/
  "httpCode" : 200, /*HTTP状态码*/
  "code": "SUCCESS", /*信息码*/
  "message": "操作成功", /*信息描述*/
  "data" : {
    /*接口响应的VO类对象*/
  },
  "list" : [], /*请求接口的类列表，查询类接口用*/
  "query" : {
    /*分页响应信息*/
    "total": 5,
    "pages": 1,
    "pageNum": 1,
    "pageSize": 10,
  },
  "map" : {
    /*除上述内容以外的其他参数*/
  }
}
```

> `data`对象要求从后端VO类对象转化而来，优先仅传入数据库表有的字段

### 3.7 错误码约定

| 错误码 | HTTP 状态码 | 场景 | 调用方处理建议 |
|--------|-------------|------|----------------|
| SUCCESS | 200 | 请求成功 | - |
| BAD_REQUEST | 400 | 参数校验失败 | 检查请求参数 |
| UNAUTHORIZED | 401 | 未登录或 Token 过期 | 跳转登录页 |
| FORBIDDEN | 403 | 无操作权限 | 提示无权限 |
| NOT_FOUND | 404 | 资源不存在 | 提示资源不存在 |
| CONFLICT | 409 | 数据冲突（如唯一约束重复） | 提示用户修改 |
| INTERNAL_ERROR | 500 | 服务器内部错误 | 提示系统异常 |
