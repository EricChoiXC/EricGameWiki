# 前端公共样式规范

> 本文档为 EricGameWiki 项目前端公共样式的统一规范公约。
> 各前端模块（wikiWeb、wikiAdmin）的样式编写应引用本文档，并在正文中声明"通用样式规范遵循本文档，不再重复编写"。
> 涉及非通用（模块特有）的样式约定，各模块文档仍需要自行编写。

## 2. 文档定位与输入依据

### 2.1 事实源策略

- **人类可读设计文档**: 本公共样式规范文档
- **机器可读契约文件**: 暂无，后续由样式变量文件（如 `tokens.scss` / `variables.css`）落地
- **同步规则**: 本文档为上游设计，实现后的样式变量文件需与本文档保持同步

### 2.2 事实源优先级

| 优先级 | 文档类型 | 冲突处理规则 |
|--------|----------|--------------|
| P0 | 本公共样式规范 | 颜色、间距、字号、断点等以本文档为准 |
| P1 | 上游 UI 设计文档 | 页面布局、组件视觉以 UI 设计文档为准 |
| P2 | 前端公共组件文档 | 组件结构与参数以公共组件文档为准 |
| P3 | 代码现状 | 实现过程中发现的问题需同步更新本文档 |

### 2.3 技术栈基线

- **CSS 预处理器**: SCSS
- **CSS 命名方案**: BEM（参考 `docs/common/开发规范.md`）
- **UI 组件库**: Element Plus
- **主题策略**: 沿用 Element Plus 官方默认主题，不进行主题色覆盖；仅在 `styles/element-plus.scss` 中按需做组件级微调
- **暗色模式**: 不支持，仅使用 Element Plus 默认亮色主题
- **样式变量来源**: Element Plus 内置 CSS 变量（`--el-*`）+ 项目自定义变量（`--color-*` / `--spacing-*` 等）

## 3. 样式文件组织约定

### 3.1 目录结构

```text
src
├─ styles/                # 全局样式
│  ├─ index.{scss,css}    # 样式统一入口
│  ├─ reset.{scss,css}    # 样式重置 / normalize
│  ├─ variables.{scss,css} # 全局样式变量（颜色、间距、字号等）
│  ├─ mixins.{scss,css}   # 公共 mixin / 工具函数
│  ├─ base.{scss,css}     # 基础样式（排版、表单、表格等）
│  └─ element-plus.{scss,css} # Element Plus 主题覆盖
└─ views/                 # 页面级样式（按模块拆分）
```

### 3.2 文件命名规范

| 文件类型 | 命名规则 | 示例 |
|----------|----------|------|
| 全局样式文件 | 小写 / kebab-case | `variables.scss` |
| 页面样式文件 | 与页面组件同名 | `HomeView.vue` 内联或 `home-view.{scss,css}` |
| 组件样式文件 | 与组件同名 | `AddressSelector.vue` 内联或 `address-selector.{scss,css}` |
| 变量文件 | 语义化命名 | `tokens.scss`、`colors.scss` |

## 14. 前端页面格式规范

> 开发过程中如果没有指定样式规范，则以本文档提供的标准样式规范为准

### admin 主页面

页面顶部为至多 120px 或 页面高度 10% 的顶部行；底部左侧为至多 360px 或 页面宽度 20% 的左侧菜单行；剩余部分为页面实际内容；

页面实际内容顶部为 `a-tabs` 组成的标签页行；固定第一个标签为 "首页" 且不可被关闭；在行右侧提供标签行左右滚动的按钮（用于大量标签页存在时的切换）和一个三点按钮（点击后下拉菜单显示所有标签页进行点击跳转，最底部提供"关闭其他"，"关闭所有"的快捷关闭选项）

### web 主页面

所有页面为独立页面，不使用多标签页设计；

### 表格

此页面规范按表形式列出的对象数据；通过 `el-row`, `el-col` 组件；

每行以 12 个栅栏宽度划分，以 1:3:1:3:1:3 比例进行分配；栅栏处显示表格边框线形成块状表格

按序显示字段名和字段值，每行最多显示 3 个字段；长信息字段值按情况占满 7 或 11 宽度；

字段名栅栏设置 `#EBEEF5` 的背景色，字段值栅栏不设置背景色

### 明细表

此页面规定明细表行数据的显示；

明细表使用 `el-table` 进行表格选择；

编辑页面首列为选择框行，固定设置列宽为 60px；其余字段列宽自适应且至少 120px；

首行为字段名行，表格设置 `#EBEEF5` 为背景色，字段居中显示；

表格显示宽度设定最大值为页面宽度的 90%；超出宽度时在明细表底部使用横向滚动条，且需保证明细表高于页面且浏览明细表时，底部滚动条固定在可见明细表底部；

编辑页面上，在明细表尾部，无缝接入同宽显示宽度的独立操作表格，居中显示新增行按钮；
