# 前端公共样式规范

> 本文档为 EricGameWiki 项目前端公共样式的统一规范公约。
> 各前端模块（wikiWeb、wikiAdmin）的样式编写应引用本文档，并在正文中声明"通用样式规范遵循本文档，不再重复编写"。
> 涉及非通用（模块特有）的样式约定，各模块文档仍需要自行编写。

## 3. 样式文件组织约定

### 3.1 目录结构

```text
src
├─ styles/                # 全局样式
│  ├─ index.{scss,css}    # 样式统一入口
│  ├─ reset.{scss,css}    # 样式重置 / normalize
│  ├─ variables.{scss,css} # 全局样式变量（颜色、间距、字号等）
│  ├─ mixins.{scss,css}   # 公共 mixin / 工具函数
│  ├─ base.{scss,css}     # 基础样式（排版、表单、表格等）
│  └─ element-plus.{scss,css} # Element Plus 主题覆盖
└─ views/                 # 页面级样式（按模块拆分）
```

### 3.2 文件命名规范

| 文件类型 | 命名规则 | 示例 |
|----------|----------|------|
| 全局样式文件 | 小写 / kebab-case | `variables.scss` |
| 页面样式文件 | 与页面组件同名 | `HomeView.vue` 内联或 `home-view.{scss,css}` |
| 组件样式文件 | 与组件同名 | `AddressSelector.vue` 内联或 `address-selector.{scss,css}` |
| 变量文件 | 语义化命名 | `tokens.scss`、`colors.scss` |

- TBD（如：全局样式统一在 `styles/` 维护；页面/组件样式优先使用 `<style scoped>`；公共可复用样式抽取为 mixin）

## 12. 编码规则

- 所有样式文件均使用 UTF-8 编码
- 禁止使用 `!important` 除非有明确说明（如覆盖第三方库）
- 禁止使用 ID 选择器编写样式，统一使用类选择器
- 禁止硬编码颜色、间距、字号值，统一引用设计令牌变量
- 公共样式统一在 `styles/` 维护，禁止在业务组件中重复定义
- 嵌套层级不超过 TBD 层（如 3 层）
- 颜色值统一使用 TBD 格式（如 HEX / RGB / HSL）
- 单位优先级：相对单位（rem / em / %） > 绝对单位（px）；具体约定 TBD
