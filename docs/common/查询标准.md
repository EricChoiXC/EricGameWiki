# 标准查询

## 标准查询结构

> 本文档为规范 `list` 等查询类接口的 `query.data` 报文格式


报文样例：

```json
{
  "query" : {
    "data" : {
      "and" : [
        {"or": [
            {"eq" :  {"fieldName" :  "张三"}},
            {"ne" :  {"fieldCode" :  "ZhangSan"}}
          ]},
        {"or" : [
            {"like" :  {"fieldAddress" :  "福建省"}},
            {"start" :  {"fieldAddress" :  "广东省"}}
          ]}
      ]
    }
  }
}
```

样例中拼出的 sql 的 where 条件应为：

```sql
select * from table_name
where (field_name = '张三' or field_code != 'ZhangSan') and (field_address like '%福建省%' or field_address like '广东省%')
```

详情样例：

| 字段项 | 说明 | 结构                        | 对应sql                                |
| --- | --- |---------------------------|--------------------------------------|
| and | 逻辑与 | `"and" : [...]`           | where ( ... and ... )                |
| or | 逻辑或 | `"or" : [...]`            | where ( ... or ... )                 |
| eq | 等于 | `"eq" : {${VO字段} : ${值}}` | field_name = '张三'                    |
| ne | 不等于 | `"ne" : {${VO字段} : ${值}}` | field_name != '张三'                   |
| like | 模糊匹配 | `"like" : {${VO字段} : ${值}}` | field_address like '%福建省%'           |
| start | 开头匹配 | `"start" : {${VO字段} : ${值}}` | field_address like '广东省%'            |
| end | 结尾匹配 | `"end" : {${VO字段} : ${值}}` | field_address like '%广东省'            |
| lt | 小于 | `"lt" : {${VO字段} : ${值}}` | field_address < '广东省'                |
| lte | 小于等于 | `"lte" : {${VO字段} : ${值}}` | field_address <= '广东省'               |
| gt | 大于 | `"gt" : {${VO字段} : ${值}}` | field_address > '广东省'                |
| gte | 大于等于 | `"gte" : {${VO字段} : ${值}}` | field_address >= '广东省'               |
| in | 集合包含 | `"in" : {${VO字段} : [${值1}, ${值2}, ...]}` | field_name in ('张三', '王五', '赵六') |
| notIn | 集合不包含 | `"notIn" : {${VO字段} : [${值1}, ${值2}, ...]}` | field_name not in ('张三', '王五', '赵六') |
